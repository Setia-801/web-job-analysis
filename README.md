# 网页制作招聘岗位数据分析

> 用数据回答三个求职问题：**这个市场给多少钱？要什么技能？专科背景的机会在哪里？**

一个端到端的数据分析项目：从招聘信息的合规采集，到 7 步数据清洗、6 维探索性分析，再到 4 条可直接执行的业务结论。项目本身也是求职作品——分析的对象，就是我正在求职的这个岗位。

## 核心结果

| 指标 | 结果 |
|---|---|
| 有效样本 | 56 → **44 条**（清洗保留率 78.6%） |
| 月薪中位数 | **¥7,275**（P25–P75：¥5,700–8,388） |
| 专科可投岗位占比 | **72.7%** |
| 技能溢价最高 | 组件库（ElementUI 类）：覆盖率仅 11.4%，溢价 **+44.3%** |
| 方向差距 | 前端开发 ¥8,725 vs 网页制作 ¥6,020（**+44.9%**） |

**四条落地结论**：① 谈薪锚定中位数，投递设 5K 下限；② CSS/HTML 是入场券，学习时间押给 JS→Vue→组件库；③ 同样的技能栈优先投「前端开发」方向；④ 72.7% 岗位专科可投，「学历不限」档薪资并不低。

## 方法亮点

- **双指纹去重**：一级「公司+岗位+薪资+城市」抓原样重发，二级同公司内 JD 前 120 字抓「改头不换面」的伪新岗位
- **薪资解析状态机**：6 种薪资写法（月薪/年薪/日薪/底薪+提成/面议/含 13薪）统一折算为月薪，解析成功率 95.5%
- **缺失值占位不删行**：不写学历的中小企业正是该岗位主要雇主，删行会造成系统性偏差
- **描述统计纪律**：右偏分布一律报告中位数与分位数，IQR 只报告不删除

## 数据与合规声明

- 当前仓库数据为**按真实字段结构构造的模拟样本**（56 条，注入 7 类典型脏数据），用于验证全流程可复现性；替换真实数据后重跑三个脚本即可更新全部结果
- 采集遵守 robots 协议与用户协议；不采集 HR 联系方式等个人信息；不绕过验证码与登录态；不对外发布原始数据集
